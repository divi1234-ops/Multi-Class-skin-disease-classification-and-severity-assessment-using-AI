# Multi-Class skin disease classification and severity assessment using AI
This project presents a deep learning-based framework for automated skin lesion analysis and classification. Dermoscopic images from the HAM10000 and ISIC 2018 datasets are processed through preprocessing and lesion analysis stages before being classified into seven predefined skin lesion categories. The framework aims to provide an efficient, accurate, and automated approach for computer-aided skin disease detection and can support researchers in developing reliable AI-assisted dermatological diagnostic systems.
